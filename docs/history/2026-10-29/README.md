# IshVerse Web

Corporate website and public front door for IshVerse. It explains the company, routes visitors to products, and provides stable public company/legal/contact surfaces.

## Current status

Documentation-first foundation. Do not infer that described roadmap behavior is already implemented.

## Stack

Next.js + React + TypeScript + Tailwind CSS + npm.

## Start here

1. `AGENTS.md`
2. `docs/README.md`
3. Relevant product/feature spec
4. Relevant architecture/design/security doc
5. Inspect implementation before editing

## Current scope

Keep the corporate site focused on IshVerse as a global technology company and on real products that exist. Do not make future hardware/cloud/defense ambitions look like currently available services.

## Working rules

- `main` is canonical.
- Use short-lived `feature/`, `fix/`, `docs/`, `refactor/`, `security/`, or `chore/` branches.
- One coherent change per PR.
- Use npm for JavaScript/TypeScript package management in IshVerse web/Node repositories.
- Do not add AI co-author attribution.
- Do not claim checks passed unless they actually ran.
- Update docs with behavioral/contract changes.

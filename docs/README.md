# IshVerse Web Documentation

This index is the routing layer for humans and AI agents. Read only the documents relevant to the current task.

- `product/` — product scope, requirements, roadmap where applicable.
- `features/` — behavior specifications where applicable.
- `architecture/` — boundaries, data flow, security, integration.
- `design/` — UI/UX and content design where applicable.
- `runbooks/` — testing, deployment, incident/release operations.
- `adr/` — architecture decisions.
- `templates/` — specs/ADR templates.

Permanent behavior belongs in specs; rationale belongs in ADRs; operational steps belong in runbooks.
